一、系统简介

什么是 AI-Care CRM？

一款面向养生馆、SPA、美发沙龙、美甲美睫、皮肤管理、产后修复等个人护理行业的智能客户管理系统。

核心价值主张

🏠 数据在自己手里

纯本地部署，客户数据只存在商户自己的电脑上，绝不上传云端

🤖 AI 专业赋能

结合各业态专业知识库，让普通技师也能提供专家级咨询

🎤 语音极简录入

语音转文字，自动提取关键标签，解放技师双手

📱 多渠道触达

短信猫自动发送，定时营销提醒，智能客户唤醒

七、AI 智能分析

核心亮点功能

利用大模型技术结合各业态专业知识库，将死板的数据转化为有温度的运营策略。

多领域专业分析

根据业态类型自动加载对应的分析领域：

业态AI 分析能力
养生馆中医体质辨识（阳虚、气虚、湿热等九种体质）
SPA/皮肤管理肤质分析（干性、油性、混合、敏感）
美发沙龙发质/头皮分析（细软、粗硬、受损、油性）
美甲美睫甲型/肤质适配分析
产后修复产后体质评估、修复优先级建议

分析依据

  • 客户自述症状：怕冷、易疲劳、长痘、肩颈酸痛等
  • 技师观察记录：面色、舌苔、皮肤状态等
  • 历史服务记录：过往服务项目及效果反馈

十一、常见问题

Q: 服务启动失败？

  • 检查端口 8888 是否被占用
  • 确认 Python 版本 ≥ 3.10
  • 查看 logs/app.log 日志

Q: AI 功能不可用？

  • 检查 config.yaml 中的 api_key
  • 确认网络可访问 AI 平台
  • 验证 API Key 是否有效

Q: 短信发送失败？

  • 错误 500：短信中心错误
  • 错误 302：SIM 卡未插好
  • 错误 300：信号弱，调整位置

Q: 如何重置系统？

  • 删除 data/wellness_crm.db
  • 重新启动 startup.bat
  • 系统会自动初始化
