# 一、系统简介

## 什么是 AI-Care CRM？

AI-Care CRM 是一款面向**养生馆、SPA、美发沙龙**等个人护理行业的智能客户管理系统。

### 核心特点
- 🏠 **本地部署** - 数据安全，无需担心泄露
- 🤖 **AI 驱动** - 智能体质分析、方案生成
- 📱 **短信触达** - 自动发送预约提醒、营销内容
- 📊 **数据可视** - 经营数据一目了然

# 二、快速开始

## 第一步：启动服务

双击 `startup.bat` 启动系统

- 自动创建数据库

- 初始化管理员账号

# 二、快速开始

## 第二步：登录系统

浏览器访问：**http://localhost:8888**

| 项目 | 值 |
|------|-----|
| 用户名 | admin |
| 密码 | admin |

> ⚠️ 首次登录后请修改密码

# 二、快速开始

## 第三步：配置 API Key

编辑 `config/config.yaml` 文件：

```yaml
llm:
  api_key: "sk-your-api-key"  # DeepSeek/Kimi等
  provider: deepseek
```

**推荐平台**：
- DeepSeek（性价比高，推荐）
- Kimi 月之暗面
- 通义千问

# 四、短信猫配置

## 安装步骤

```
1. 插入 SIM 卡 → 2. 连接 USB → 3. 确认串口
```

**设备管理器显示**：
```
USB-SERIAL CH340 (COM3) ✓
```

---

# 四、短信猫配置

## 配置文件

编辑 `config/config.yaml`：

```yaml
channels:
  ml307a:
    enabled: true
    port: ''           # 留空自动扫描
    carrier: auto      # 自动检测运营商
```

---

# 五、常见问题

## Q1: 服务启动失败

**检查项**：
1. 端口 8888 是否被占用
2. Python 版本是否 3.10+
3. 配置文件格式是否正确

---

# 五、常见问题

## Q2: AI 功能不可用

**解决方法**：
1. 检查 `config.yaml` 中的 `api_key`
2. 确认网络可访问 AI 平台
3. 查看日志 `logs/app.log`

---

# 五、常见问题

## Q3: 短信发送失败

| 错误码 | 原因 | 解决 |
|--------|------|------|
| 500 | 短信中心错误 | 联系运营商 |
| 302 | 无 SIM 卡 | 重新插卡 |
| 300 | 信号弱 | 移动设备位置 |
