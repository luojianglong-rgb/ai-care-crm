## 常见问题排查

### 问题 1: 端口被占用
**症状**: 启动时报端口 8888 已占用
**解决**: 
```bash
netstat -ano | findstr ":8888"
taskkill /F /PID <进程 ID>
```

### 问题 2: 找不到模块 'jwt'
**症状**: ImportError: No module named 'jwt'
**原因**: PyJWT 未安装
**解决**: 
```bash
.venv/Scripts/pip install PyJWT
```

### 问题 3: 配置文件不存在
**症状**: 启动时提示 config.yaml 不存在
**解决**: 
```bash
copy src\config.yaml.template src\config.yaml
```

### 问题 4: 虚拟环境损坏
**症状**: pip 安装报错 [WinError 5] 拒绝访问
**解决**:
```bash
# 停止所有 Python 进程
# 删除 .venv 目录
rm -rf .venv
# 重新创建
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
```

## 小白用户安装步骤

1. **安装 Python**
   - 下载 Python 3.10+
   - 安装时勾选 "Add Python to PATH"

2. **运行安装向导**
   - 双击 `install.bat`
   - 等待自动安装完成

3. **配置系统**
   - 打开 `src\config.yaml`
   - 填写 API Key（可暂不填，使用基础功能）

4. **启动服务**
   - 双击 `startup.bat`
   - 浏览器自动打开

5. **登录系统**
   - 访问 http://localhost:8888
   - 账号：admin
   - 密码：admin
