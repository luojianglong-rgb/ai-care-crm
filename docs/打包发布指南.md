# AI-Care CRM 打包发布指南

## 一、打包前准备

### 1. 环境要求
- **操作系统**: Windows 10/11 (64 位)
- **Python**: 3.10+ (项目使用 3.14)
- **Node.js**: 18+ (用于编译前端)
- **PyInstaller**: `pip install pyinstaller`
- **Inno Setup**: [下载安装](https://jrsoftware.org/isdl.php)（创建安装包）

### 2. 清理开发环境
```bash
# 删除临时文件
del /s /q __pycache__
del /s /q *.pyc
del /s /q .venv  # 打包时不依赖虚拟环境

# 清理日志
del /s /q logs\*

# 清理数据库（可选，用户首次启动会创建）
del src\wellness_crm.db
```

---

## 二、打包步骤

### 步骤 1: 编译前端
```bash
cd frontend
npm install
npm run build
```

编译后生成 `frontend/dist/` 目录（约 400-600KB）。

### 步骤 2: 使用 PyInstaller 打包

#### 方法 A：使用 spec 文件（推荐）
```bash
cd D:\claudeCode_wks\wellness-crm
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller --clean ai_care_crm.spec
```

#### 方法 B：一键打包脚本
```bash
# 执行打包脚本
build.bat
```

打包完成后，生成：
- `dist/AI-Care-CRM/AI-Care-CRM.exe` - 主程序
- `dist/AI-Care-CRM/frontend/dist/` - 前端静态文件
- `dist/AI-Care-CRM/src/config.yaml.template/` - 配置模板

### 步骤 3: 创建安装包（Inno Setup）

1. 打开 Inno Setup Compiler
2. 加载 `installer.iss`
3. 点击 **Build → Compile**
4. 生成安装包：`Output/AI-Care-CRM-Setup-1.0.0.exe`

## 四、用户安装流程

### 使用安装包安装
1. 双击 `AI-Care-CRM-Setup-1.0.0.exe`
2. 选择安装目录（默认 `C:\Program Files\AI-Care-CRM`）
3. 创建桌面快捷方式（可选）
4. 安装完成，自动启动程序

### 首次启动
1. 系统自动生成 `config.yaml`
2. 弹出配置向导（可选）：
   - 设置管理员密码
   - 填写大模型 API Key
   - 选择业态类型
   - 输入激活码（可选）
3. 进入主界面

## 五、配置说明

### config.yaml 关键配置
```yaml
# 门店信息
store:
  name: "您的门店名称"
  business_type: tcm_wellness

# AI 配置
llm:
  api_key: "sk-xxx"  # 必须填写
  provider: deepseek
  model: deepseek-chat

# 激活码
license:
  key: ""  # 留空=免费版

# 渠道配置
channels:
  default: ml307a
  ml307a:
    enabled: false  # 使用短信猫时启用
    port: ''        # 串口号，留空自动扫描
```

## 六、常见问题

### Q1: 打包后启动报错 "找不到模块"
**解决：**
- 检查 `ai_care_crm.spec` 中的 `hiddenimports`
- 添加缺失的模块名

### Q2: 前端页面无法访问
**解决：**
- 确认 `frontend/dist/` 目录已复制到打包目录
- 检查 main.py 中的 `FRONTEND_DIST_PATH` 路径

### Q3: 配置文件未生成
**解决：**
- 检查 `config.yaml.template` 是否打包
- 查看日志文件 `logs/app.log`

### Q4: ML307A 短信猫无法识别
**解决：**
- 检查 USB 驱动是否安装
- 确认串口号配置正确

---

### 减小打包体积
1. 移除不必要的模块（在 spec 文件的 `excludes` 中添加）
2. 使用 `upx` 压缩（已启用）
3. 不包含测试文件

### 提高启动速度
1. 使用 `--onefile` 单文件模式（但启动稍慢）
2. 减少 imports 数量

### 增强安全性
1. 使用 Nuitka 代替 PyInstaller（编译为 C++）
2. 添加代码混淆（pyobfuscate）
3. 添加代码签名证书（需要购买）
