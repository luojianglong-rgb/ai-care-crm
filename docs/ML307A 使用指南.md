## 二、设备连接

### 1. 插入 SIM 卡
```
┌─────────────────┐
│  ╔═══════════╗  │  ← 侧面 SIM 卡槽
│  ║  ML307A   ║  │
│  ╚═══════════╝  │
│       ▲         │
│    USB 接口      │
└───────┼─────────┘
        │
     插电脑 USB
```

### 2. 连接电脑
- USB 线连接设备和电脑
- 等待 Windows 自动安装驱动（CH340/CP2102）
- 设备指示灯亮起表示通电正常

### 3. 确认串口号
打开设备管理器 → 查看"端口 (COM 和 LPT)"：
```
USB-SERIAL CH340 (COM3)  ← 这就是串口号
```

## 三、系统配置

### 1. 修改 `src/config.yaml`
```yaml
channels:
  default: ml307a
  ml307a:
    enabled: true      # 启用
    port: ''           # 留空自动扫描，或指定"COM3"
    baudrate: 115200   # 波特率
    sim_pin: ''        # SIM 卡 PIN 码（一般不需要）
    retry_count: 2     # 失败重试次数
```

### 2. 重启后端服务
```bash
# 停止现有服务（Ctrl+C）
# 重新启动
cd src
..\.venv\Scripts\python main.py
```

## 五、发送短信

### 方式一：自动发送（推荐）
系统会自动使用 ML307A 发送营销任务（当 `default: ml307a` 时）。

### 方式二：手动发送
```bash
curl -X POST "http://localhost:8000/api/v1/campaigns/tasks/{task_id}/send" \
  -H "Authorization: Bearer {token}"
```

### 方式三：微信 RPA 备用
如果 ML307A 发送失败，系统会自动切换到微信 RPA。

## 七、常见问题

### Q1: 设备无法识别
**解决：**
1. 更换 USB 口或 USB 线
2. 手动安装 CH340 驱动：https://www.wch.cn/downloads/CH341SER_ZIP.html
3. 查看设备管理器是否有黄色感叹号

### Q2: "SIM 卡未就绪"
**解决：**
1. 检查 SIM 卡是否插好（金属面朝下）
2. 确认 SIM 卡已开通短信功能
3. 如需要 PIN 码，在 config.yaml 中配置 `sim_pin`

### Q3: 信号弱 (CSQ < 10)
**解决：**
1. 调整设备位置（靠近窗户）
2. 更换天线（IPEX 接口）
3. 使用 USB 延长线把设备放在高处

### Q4: 短信发送失败
**查看错误信息：**
- `+CMS ERROR: 500` → 短信中心号码错误（联系运营商）
- `+CMS ERROR: 302` → 无 SIM 卡
- `+CMS ERROR: 300` → 信号弱

## 八、AT 指令调试

如需手动调试，可使用串口工具：

### 工具推荐
- **SSCOM**：https://www.dream4us.org/
- **Putty**：选择 Serial 模式

### 常用指令
```bash
AT                      # 测试连接，返回 OK
AT+CSQ                  # 查询信号强度
AT+CPIN?                # 查询 SIM 卡状态
AT+COPS?                # 查询运营商
AT+CMGF=1               # 设置文本模式
AT+CSCS="UCS2"          # 设置 UCS2 编码
AT+CMGS="13800138000"   # 发送短信（输入内容后按 Ctrl+Z）
```

## 九、注意事项

1. **发送频率控制**：建议间隔 3-5 秒/条，避免被运营商判定为群发
2. **内容审核**：避免发送营销敏感词（贷款、中奖等）
3. **散热**：长时间使用时确保设备通风
4. **防雷击**：室外天线需加防雷器
